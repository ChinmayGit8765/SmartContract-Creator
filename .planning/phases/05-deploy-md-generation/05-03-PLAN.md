<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| wizard opts → deployMeta → DEPLOY.md on disk | User's validated contract name + options become a Markdown file written to the user-chosen directory. |
| --out path → deployPath | The deploy path is derived by suffix-swap on the already-resolved .sol path; no new path joins. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Tampering (markdown injection via contract name / address) | create.ts deploy-doc write + sections echoing meta.contractName | mitigate | meta.contractName is the wizard-validated Solidity identifier (compile-verify rejects invalid `contract X` names before deployMeta runs); the doc interpolates only the validated name + fixed placeholder tokens (`<YOUR_WALLET_ADDRESS>` etc.), never raw user-supplied addresses or RPC URLs. No recipient address is taken as free text into the doc. |
| T-05-05 | Tampering (path traversal via --out) | deployDocPath / writeFile | mitigate | deployPath is a pure suffix-swap on the SAME resolved outPath the .sol uses (no extra path.join); reuses Phase 1 path resolution + the overwrite gate. No new traversal surface. |
| T-05-06 | DoS / data loss (silent overwrite) | confirmOverwriteMany | mitigate | Both target files are checked up front and the user is prompted once (unless --force); declining throws E_FILE_EXISTS. No file is overwritten without consent. |
| T-05-07 | Tampering (artifact on compile failure) | dispatcher ordering | mitigate | The DEPLOY.md write is strictly after the compile-verify gate (D-10); a compile failure throws before any write — E2E asserts neither file exists on failure. |
| T-05-03 | Repudiation / trust | wizard refactor + DEPLOY.md warnings | mitigate | Single-source centralizationWarnings (05-01); wizard-parity.spec.ts locks byte-identical critical warnings so the refactor cannot silently change disclosed risks. |
| T-05-SC | Tampering | npm/pip/cargo installs | n/a | Phase 5 installs ZERO new packages. No install task. |
</threat_model>
