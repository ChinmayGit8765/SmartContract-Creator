<objective>
Ship `smartc doctor`: a read-only environment probe that detects Node, the
bundled solc, and the optional Solana/Ollama toolchains, reports each tool's
found/version/status, and exits non-zero only when a REQUIRED tool is
missing/outdated so it is scriptable in CI (DOCTOR-03).

Purpose: a prerequisite for the graceful degradation of Phase 7 (SPL) and Phase 8
(AI) — both point users at `smartc doctor` when their optional toolchain is
absent.
Output: a `src/doctor/` module (types/probes/index/README), a `doctor` command,
program wiring, and tests.
</objective>

<design>
- ProbeResult contract (types.ts): { key, name, found, version, status, required, purpose, note? }. The `--json` shape is a stable public contract.
- Probes (probes.ts): probeNode (process.versions.node vs MIN_NODE_MAJOR=20), probeSolc (safeReadVersion), and three shelled probes via a never-throws runVersion helper (execFile, 4s timeout, shell:true on win32 to resolve .cmd shims). extractVersion pulls semver from noisy --version output.
- Orchestrator (index.ts): runProbes() runs the three shelled probes in parallel; doctorExitCode() = 0 iff every required tool is ok.
- Command (commands/doctor.ts): cli-table3 table by default; --json machine shape; sets process.exitCode (not process.exit) so the report still prints and tests can read the code; newbie mode surfaces install pointers.
- Only Node + bundled solc are `required` — the EVM core works without the Solana/AI tools, so a fresh Node-only machine exits 0.
</design>
