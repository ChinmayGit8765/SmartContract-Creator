<objective>
Add the SPL token (Solana / Anchor) template end-to-end: wizard with explicit
authority footgun prompts, an Anchor-program generator, a graceful-degradation
compile-verify adapter (anchor build when present, skip-with-warning when absent),
and the chain:"solana" DEPLOY.md sections that plug into the Phase 5 chain-keyed
registry.

Purpose: completes template coverage (the 4th template) and validates the
chain-agnostic seams built in Phases 3 (compileVerify) and 5 (deploy registry).
The graceful-degradation path is the primary, well-tested path because the Anchor
toolchain is heavy and frequently absent.
</objective>

<design>
- Plugin (src/templates/spl/): validators (name<=32, symbol<=10, decimals 0-9, whole supply), opts, naming (snake_case .rs), generate (option-driven Anchor lib.rs — mint/freeze authority, metadata CPI, revoke-after-mint), deployMeta (chain:"solana", standard:"spl"), wizard (explicit no-default authority selects + single-source warnings), index.
- Compile-verify (src/compiler/solana.ts + index.ts): compileVerify now returns CompileResult { warnings, skipped, skipReason? }; solana delegates to compileVerifySolana which probes anchor (reuses doctor's runVersion), skips when absent (SPL-05), or scaffolds a version-coherent scratch workspace + `anchor build` (COMP-02). Both side effects injectable for tests.
- Deploy (src/deploy/): DeployFlags gains spl flags (mintAuthorityRetained/freezeAuthorityRetained/metadata); centralizationWarnings gains the spl authority warnings; constructorArgs gains splConstructorArgs (token params, not EVM ctor); sections/solana/* + a solana branch in sectionsFor render header/warnings/safety/params/spl-token-cli/anchor/solscan; deployDocPath also swaps .rs.
- Dispatcher (create.ts): handles skipped (warn + still write — SPL-05); EVM-only solc nextStep gated on chain==="evm". cli.ts registers the spl template.
</design>

</verification>
